# Exportação de Dados

A exportação permite salvar datasets processados em diferentes formatos para reutilização, compartilhamento ou integração com outros sistemas.

---

#  Formatos disponíveis

## CSV

Formato simples e universal.

Melhor para:
- Compartilhamento
- Planilhas
- Sistemas diversos

---

## Excel

Formato compatível com planilhas eletrônicas.

Melhor para:
- Relatórios
- Usuários não técnicos
- Análise manual

---

## JSON

Formato estruturado utilizado em APIs e aplicações web.

Melhor para:
- Integração de sistemas
- Aplicações modernas
- Dados hierárquicos

---

## Parquet

Formato otimizado para Big Data e análise de alto desempenho.

Melhor para:
- Machine Learning
- Data Lakes
- Grandes volumes

---

## LaTeX

Exporta tabelas para documentos científicos.

Melhor para:
- Artigos acadêmicos
- Relatórios técnicos
- Publicações científicas

---

## ZIP

Compacta múltiplos arquivos em um único pacote.

Melhor para:
- Backup
- Distribuição
- Compartilhamento completo

---

# Objetivo da Exportação

Permitir reutilização e compartilhamento dos resultados obtidos.

---

#  Boas práticas

- Escolha formatos adequados
- Utilize compactação para grandes volumes
- Padronize nomes de arquivos
- Organize versões dos datasets
- Documente transformações aplicadas
